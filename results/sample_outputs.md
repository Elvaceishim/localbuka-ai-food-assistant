# Summary

The recommendation engine uses a weighted scoring system based on:

- Cuisine preference (35 points)
- Price range match (25 points)
- Dietary restriction match (20 points)
- Spice preference match (10 points)
- Location match (5 points)
- Restaurant rating bonus (up to 5 points)

Recommendations are ranked by total score and include explanation metadata to improve transparency and debugging.
